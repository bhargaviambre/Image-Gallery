# Image-Gallery

A responsive and interactive image gallery built using **HTML, CSS, JavaScript**.
The gallery allows users to browse images by category, search by category, and view images in a larger lightbox.

## Features
-Display 12 sample images
-Search images by category
-Filter images by category
-CSS grid layout
-Interactive lightbox
-Close lightbox using close button
-Close lightbox by clicking outside the image
-Responsive design for tablet and mobile
-Black, white, and gray theme
-DOM manipulation using JavaScript

## Technologies Used
* HTML5-Page Structure
* CSS3-Styling, CSS grid and responsive design
* JavaScript-Filtering, search, lightbox, and DOM manipulation
